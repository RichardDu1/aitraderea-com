## Overview
Survivorship bias occurs when backtesting only includes assets that survived to the present, ignoring those that were delisted, merged, or went bankrupt. This guide automates detection by scraping corporate actions via SEC EDGAR, applying NLP to classify events, and flagging biased datasets.

## Prerequisites
- Python 3.8+
- Libraries: pandas, nltk, requests, beautifulsoup4, backtrader
- SEC EDGAR API key (free)

## Step 2: NLP Classification of Corporate Actions
Use NLTK with a custom classifier to label each filing as 'survivorship-relevant' (e.g., bankruptcy) or not.

```python
import nltk
from nltk.classify import NaiveBayesClassifier

# Pre-labeled training data (example)
train_data = [
    ({"word": "bankruptcy"}, "survivorship"),
    ({"word": "merger"}, "survivorship"),
    ({"word": "dividend"}, "normal"),
]
classifier = NaiveBayesClassifier.train(train_data)

def classify_filing(text):
    features = {word: True for word in text.split()}
    return classifier.classify(features)
```

## Step 3: Cross-Reference with Backtesting Data
Load your historical price data (e.g., from Yahoo Finance) and check if any tickers have survivorship events during the backtest period. Flag those tickers.

```python
import pandas as pd

# Load backtest universe
universe = pd.read_csv('backtest_universe.csv')

# For each ticker, check if any survivorship event exists
biased_tickers = []
for ticker in universe['ticker']:
    events = fetch_8k_filings(ticker, '2000-01-01', '2020-12-31')
    for event in events:
        if classify_filing(event['text']) == 'survivorship':
            biased_tickers.append(ticker)
            break
```

## Step 4: Adjust Backtest or Exclude Biased Data
Remove or adjust for biased tickers in your backtesting engine (e.g., Backtrader).

```python
import backtrader as bt

cerebro = bt.Cerebro()
# Only add data for non-biased tickers
for ticker in universe['ticker']:
    if ticker not in biased_tickers:
        data = bt.feeds.YahooFinanceData(dataname=ticker, fromdate=..., todate=...)
        cerebro.adddata(data)
```
