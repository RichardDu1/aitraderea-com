## Real-Time Market Regime Classification Using Unsupervised Learning on Order Book Imbalance Data

### Overview
This workflow guides you through building a real-time market regime classifier using unsupervised learning on order book imbalance data. The classifier identifies market regimes (e.g., trending, ranging, volatile) to adapt trading strategies dynamically.

### Prerequisites
- **Python 3.8+** installed
- **API keys** for a cryptocurrency exchange (e.g., Binance, Coinbase Pro)
- **AWS account** (optional, for SageMaker deployment)
- Basic knowledge of Python, pandas, and machine learning

### Step 1: Data Collection - Order Book Imbalance
Order book imbalance (OBI) measures the difference between bid and ask volumes. We'll collect real-time order book snapshots using the `ccxt` library.

```python
import ccxt
import pandas as pd
import time

exchange = ccxt.binance()
symbol = 'BTC/USDT'

def get_order_book_imbalance():
    order_book = exchange.fetch_order_book(symbol)
    bids = order_book['bids']
    asks = order_book['asks']
    bid_volume = sum([bid[1] for bid in bids[:10]])
    ask_volume = sum([ask[1] for ask in asks[:10]])
    imbalance = (bid_volume - ask_volume) / (bid_volume + ask_volume)
    return imbalance

# Collect data over time
imbalance_data = []
for i in range(1000):
    imb = get_order_book_imbalance()
    imbalance_data.append({'timestamp': time.time(), 'imbalance': imb})
    time.sleep(1)

df = pd.DataFrame(imbalance_data)
```

### Step 2: Feature Engineering
Create features from OBI and price data to capture market dynamics.

```python
import numpy as np

# Compute rolling statistics
df['imbalance_ma'] = df['imbalance'].rolling(window=10).mean()
df['imbalance_std'] = df['imbalance'].rolling(window=10).std()
df['imbalance_momentum'] = df['imbalance'].diff(periods=5)

# Add price features (e.g., returns, volatility)
# Assume we also collect price data
prices = [exchange.fetch_ticker(symbol)['last'] for _ in range(1000)]
df['price'] = prices
df['returns'] = df['price'].pct_change()
df['volatility'] = df['returns'].rolling(window=10).std()

# Drop NaN values
df_clean = df.dropna().reset_index(drop=True)
```

### Step 3: Unsupervised Learning for Regime Classification
Use clustering (e.g., K-Means) to identify regimes. We'll use `scikit-learn`.

```python
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

# Select features
features = ['imbalance', 'imbalance_ma', 'imbalance_std', 'imbalance_momentum', 'returns', 'volatility']
X = df_clean[features]

# Standardize
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Determine optimal number of clusters (e.g., using elbow method)
# For simplicity, assume 3 regimes
kmeans = KMeans(n_clusters=3, random_state=42)
df_clean['regime'] = kmeans.fit_predict(X_scaled)
```
