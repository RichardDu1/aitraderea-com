## Step 2: Extract Data from Backtest Reports

Use PDF plumber to parse backtest reports. For MT5, export reports as PDF or CSV.

```python
import pdfplumber
import pandas as pd

def extract_backtest_metrics(pdf_path):
    with pdfplumber.open(pdf_path) as pdf:
        text = ""
        for page in pdf.pages:
            text += page.extract_text()
    # Use regex or NLP to find metrics like total profit, drawdown, win rate
    import re
    profit = re.search(r'Total Net Profit[\s:]+([\d.]+)', text)
    drawdown = re.search(r'Max Drawdown[\s:]+([\d.]+)%', text)
    win_rate = re.search(r'Win Rate[\s:]+([\d.]+)%', text)
    return {
        'profit': float(profit.group(1)) if profit else None,
        'drawdown': float(drawdown.group(1)) if drawdown else None,
        'win_rate': float(win_rate.group(1)) if win_rate else None
    }
```

## Step 3: NLP for Strategy Description Analysis

Use spaCy to extract entities from strategy descriptions (e.g., indicators, timeframes).

```python
import spacy
nlp = spacy.load("en_core_web_sm")

def extract_strategy_features(description):
    doc = nlp(description)
    indicators = [ent.text for ent in doc.ents if ent.label_ == "PRODUCT"]  # custom NER
    # Alternatively, use keyword matching
    return indicators
```

## Step 4: Build ML Model for Optimization

Train a regression model to predict strategy performance based on parameters.

```python
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split

def train_optimizer(features_df, target='profit'):
    X = features_df.drop(columns=[target])
    y = features_df[target]
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
    model = RandomForestRegressor(n_estimators=100)
    model.fit(X_train, y_train)
    return model
```
