## Overview

This workflow automates the testing of broker execution quality (slippage, latency, fill rate) across ECN/STP brokers using MetaTrader 5 (MT5), Python, and free data tools. It enables trading operations analysts to compare brokers objectively and make data-driven decisions.

## Prerequisites

- **MT5** installed on a Windows VPS or local machine
- **Python 3.8+** with packages: `MetaTrader5`, `pandas`, `numpy`, `matplotlib`, `requests`, `schedule`
- **Jupyter Notebook** (optional but recommended for analysis)
- **Forex Tester 5** (optional for historical simulation)
- **Broker demo accounts** (at least 2 for comparison)

## Step 1: Set Up MT5 and Python Environment

1. Install MT5 from your broker's website.
2. Open MT5, go to **Tools > Options > Expert Advisors**, and enable **Allow automated trading**.
3. Install Python packages:
   ```bash
   pip install MetaTrader5 pandas numpy matplotlib requests schedule
   ```
4. Create a new Python script `broker_test.py`.

## Step 2: Connect to MT5 and Retrieve Account Info

```python
import MetaTrader5 as mt5
```

## Step 3: Define Test Parameters

Set the symbols, order types, and lot sizes to test. For example:

```python
symbols = ["EURUSD", "GBPUSD", "USDJPY"]
order_types = [mt5.ORDER_TYPE_BUY, mt5.ORDER_TYPE_SELL]
lot_sizes = [0.01, 0.1, 1.0]
num_orders = 100  # per symbol/type/lot
```

## Step 4: Execute Orders and Record Slippage

Create a function to send market orders and capture execution data:

```python
def test_execution(symbol, order_type, volume):
    request = {
        "action": mt5.TRADE_ACTION_DEAL,
        "symbol": symbol,
        "volume": volume,
        "type": order_type,
        "price": 0.0,  # market order
        "deviation": 10,  # slippage tolerance in points
        "magic": 123456,
        "comment": "broker test",
        "type_time": mt5.ORDER_TIME_GTC,
        "type_filling": mt5.ORDER_FILLING_IOC,
    }
    result = mt5.order_send(request)
    if result.retcode != mt5.TRADE_RETCODE_DONE:
        return None
    # Get actual execution price from order
    order = mt5.history_deals_get(ticket=result.order)
    if order:
        return {
            "symbol": symbol,
            "type": "buy" if order_type == mt5.ORDER_TYPE_BUY else "sell",
            "volume": volume,
            "requested_price": request["price"],
            "executed_price": order[0].price,
            "slippage": order[0].price - request["price"],
            "time": order[0].time
        }
    return None
```

Loop through all combinations and collect data:

```python
results = []
for symbol in symbols:
    for order_type in order_types:
        for lot in lot_sizes:
            for _ in range(num_orders):
                data = test_execution(symbol, order_type, lot)
                if data:
                    results.append(data)
```

## Step 5: Analyze Results

Convert to DataFrame and compute statistics:

```python
df = pd.DataFrame(results)
stats = df.groupby(['symbol', 'type', 'volume']).agg(
    avg_slippage=('slippage', 'mean'),
    max_slippage=('slippage', 'max'),
    min_slippage=('slippage', 'min'),
    std_slippage=('slippage', 'std'),
    fill_rate=('slippage', 'count')
).reset_index()
print(stats)
```

## Step 6: Visualize Slippage Distribution

```python
import matplotlib.pyplot as plt
```
