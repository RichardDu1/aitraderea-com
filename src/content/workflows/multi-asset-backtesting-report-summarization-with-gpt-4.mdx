## Multi-Asset Backtesting Report Summarization with GPT-4

### Overview
This workflow automates the summarization of multi-asset backtesting reports using GPT-4. It extracts key performance metrics (e.g., Sharpe ratio, max drawdown, win rate) and generates concise, actionable summaries for hedge fund analysts.

### Prerequisites
- Python 3.8+ installed
- OpenAI API key with GPT-4 access
- Backtesting reports in CSV or JSON format (e.g., from MetaTrader, TradingView, or custom backtester)

### Step 1: Prepare Your Backtesting Data
Ensure your backtesting reports are structured with columns for each asset, including metrics like:
- `asset` (e.g., EURUSD, BTCUSD)
- `total_return`
- `sharpe_ratio`
- `max_drawdown`
- `win_rate`
- `num_trades`
- `profit_factor`

Example CSV snippet:
```
asset,total_return,sharpe_ratio,max_drawdown,win_rate,num_trades,profit_factor
EURUSD,0.12,1.5,0.08,0.65,200,1.8
BTCUSD,0.25,1.2,0.35,0.55,150,1.4
```

### Step 3: Load and Analyze Data with Pandas
Create a Python script to load the CSV and compute aggregate statistics:
```python
import pandas as pd

df = pd.read_csv('backtest_results.csv')

# Aggregate across assets
summary = df.agg({
    'total_return': 'mean',
    'sharpe_ratio': 'mean',
    'max_drawdown': 'max',
    'win_rate': 'mean',
    'num_trades': 'sum',
    'profit_factor': 'mean'
}).to_dict()

print(summary)
```

### Step 5: Summarize with GPT-4
Use the OpenAI API to generate a natural language summary:
```python
import openai

openai.api_key = 'your-api-key'

prompt = f"""
You are a hedge fund analyst. Summarize the following multi-asset backtest results:

Aggregate Metrics:
- Average Total Return: {summary['total_return']:.2%}
- Average Sharpe Ratio: {summary['sharpe_ratio']:.2f}
- Maximum Drawdown: {summary['max_drawdown']:.2%}
- Average Win Rate: {summary['win_rate']:.2%}
- Total Trades: {summary['num_trades']}
- Average Profit Factor: {summary['profit_factor']:.2f}

Provide a concise summary highlighting the best and worst performing assets, risk concerns, and overall portfolio health.
"""

response = openai.ChatCompletion.create(
    model="gpt-4",
    messages=[{"role": "user", "content": prompt}],
    max_tokens=500
)

print(response.choices[0].message.content)
```

### Step 6: Automate and Schedule
Wrap the script in a function and schedule it to run daily using cron (Linux) or Task Scheduler (Windows). Output the summary to a Slack channel or email.

### Best Practices
- **Drawdown Limits**: Set a maximum drawdown threshold (e.g., 20%) and flag assets exceeding it.
- **Win Rate**: Compare win rates against benchmark (e.g., 50%).
- **Broker Compatibility**: Ensure your backtest data format matches your broker's export (e.g., MetaTrader CSV).
- **Risk Management**: Include position sizing and VaR metrics in the summary.

### Troubleshooting
- **API Errors**: Check your OpenAI API key and quota.
- **Data Format**: Ensure CSV columns match the expected names.
- **Large Reports**: For >100 assets, consider chunking the data.
